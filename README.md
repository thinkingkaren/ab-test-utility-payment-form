# A/B-тест новой формы оплаты ЖКХ

Учебный проект по продуктовой аналитике. Цель — оценить эффективность новой формы оплаты ЖКХ и определить, стоит ли внедрять её для всех пользователей.

## Задача

Сравнить конверсию старой и новой форм оплаты, проанализировать воронку платежа и проверить статистическую значимость различий между группами.

## Данные

Использован Excel-файл с двумя листами: «Пользователи» и «Платежи».

- Период теста: 1–30 апреля 2024 года.
- После очистки данных осталось 1 500 пользователей: 750 в группе A и 750 в группе B.
- Группа A использовала старую форму оплаты, группа B — новую.

## Методы

- Разведочный анализ данных (EDA).
- Очистка данных и обработка аномалий.
- Агрегация платежей на уровне пользователей.
- Построение воронки конверсии.
- Проверка гипотезы с помощью критерия хи-квадрат.
- Расчёт доверительного интервала для разницы конверсий.

## Основные результаты

- Конверсия старой формы — 65,7%.
- Конверсия новой формы — 80,4%.
- Абсолютный прирост конверсии — 14,7 процентного пункта.
- Относительный прирост — 22,3%.
- 95% доверительный интервал разницы: от 10,2 до 19,1 процентного пункта.
- Результат проверки гипотезы: χ² = 40,25, p-value ≈ 2,24 × 10⁻¹⁰.

Различие конверсий статистически значимо при уровне значимости 0,05.

## Вывод и рекомендация

В проведённом тесте новая форма оплаты показала более высокую конверсию. Результаты поддерживают решение о её внедрении. После запуска рекомендуется повторно проверить конверсию через 2–3 недели и убедиться, что улучшение сохраняется.
